## 已确认的推理契约

原题：过 M(1,0) 的直线 LineOf(A,B) 与 y²=2x 交于 A、B，O 为原点，OA、OB 的斜率和为 1，求直线方程。输入只使用原始 facts/query；弱标注 RM54 与斜率推导不符，仍保留数据不改。

| 环节 | 前提与输出 | 当前状态 |
| --- | --- | --- |
| 初态解析 | 规范直线身份，保存过点关系、无序交点集合、斜率和及定义域要求；Origin 提供 (0,0) | 本批已实现 |
| RM78 参数化／消元 | 绑定直线、M、曲线方程及两交点声明；排除水平分支后引入局部实参数 u，提出 x=uy+1、y²−2uy−2=0 和根对关联 | 下一批 |
| RM42/43 符号模式 | 绑定同一消元事实与无序命名根对，分别提出 S=2u、P=−2；记录 Δ=4u²+8>0 的证据 | 待扩展；当前数值模式不能直接使用 |
| RM55 斜率约束模式 | 消费已有 S/P、原点／曲线上点关系及斜率和，验证分母，提出 −2u=1 的唯一解 u=−1/2 | 后续批次 |
| 统一归约／查询 | 应用器用已知 u 归约直线方程及依赖结果；查询只读取 2x+y−2=0 | 归约范围需随符号结构扩展；本批查询仅读取已存在且不含待定参数的方程 |

**方向覆盖**：x=u(y−y_M)+x_M 不包含水平直线。ID56 过 M 的水平线 y=0 与曲线只有原点一个交点，不满足给定的两个不同交点，因此可排除。后续实现须计算并记录该检查；不能把这个例题结论推广到所有过点直线。竖直线 x=1 对应 u=0，仍在候选族内。

**参数作用域**：u 是模型生成的局部实辅助量，须以直线／应用范围分配稳定标识，不复用或覆盖原题同名 m/t/u。初态不会提前创建它；重复 RM78 应复用已提交标识，不生成新自由度。下一批还需定义参数与派生直线的原子提交。

**命名根关联**：给定 {A,B} 是无序集合；消元根集合对应 {A.y,B.y}，每个点的 x 与其自己的 y 通过同一坐标映射相连。不得按正负／大小擅自把某根命名 A。当前 NamedIntersection 只记录给定集合，尚不是已生成的根关联事实；后续关联须引用它和 IntersectionReduction 两项来源。

**斜率非零条件**：原题斜率有定义要求 x_A−x_O≠0、x_B−x_O≠0；初态仅以点对保存要求。后续由 P=−2 证明 y_A、y_B 非零，再由 x_i=y_i²/2 证明 x_i≠0，才允许 y_i/x_i=2/y_i。RM55 不得内部补做 RM43，缺少非零证据时停止。−2S/P 的符号容易混淆，本题正确斜率和为 2S/P=−2u。

独立数学核验：u=−1/2 时两点集合为 {(2,−2),(1/2,1)}，斜率为 −1、2，直线过 M；该核验不是本批执行器输出。

## 核心定义与保存内容

| 定义 | 操作／信息及后续用途 |
| --- | --- |
| NamedLine / named_lines | 保存直线内部身份和规范排序的两端点标签；排序用于身份去重，不代表坐标或根大小 |
| register_named_line | 校验两个不同的已声明点标签，将 LineOf(A,B) 和 LineOf(B,A) 登记为同一 @line:A:B，并记录引用来源，供查询与关系共同绑定 |
| NamedIntersection / named_intersections | 保存事实 ID、曲线、直线、无序两交点标签及原文；由解析生成，供 RM78 后续建立根对关联 |
| SlopeSum / slope_sums | 保存公共起点、两个终点、数值斜率和与非零 x 差要求；供 RM55 后续验证分母和建立约束。base_point 不限定为原点 |
| parse_named_line_fact | 识别本批三种关系，登记身份／给定点归属／斜率要求；其他语法交回现有解析器。交点声明附带的归属记录引用原事实 ID |
| NamedLineQuery | 只表示求指定命名直线的方程，不证明交点存在；即使仅查询 LineOf(A,B)，也不会生成归属或根 |
| from_facts / extract_answer | 前者接入结构解析，并将 Origin 按定义记录为 Point 和来源明确的 (0,0)；后者只读唯一所属 line 方程，缺失、多方程或仍含辅助参数时返回 None |

本批 SlopeSum 的 nonzero_x_differences 保存 (终点,起点) 点对，含义是对应 x 坐标差必须非零；尚未实例化为已证明的标量约束。Origin 坐标来自类型定义，不是定理步骤；重复显式坐标暂拒绝，即便数值相同。
