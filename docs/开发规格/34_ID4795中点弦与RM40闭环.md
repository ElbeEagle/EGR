# ID4795：匿名中点弦与 RM40 闭环

## 契约与结果

输入 `Coordinate(MidPoint(InterceptChord(l,G)))=(1/2,1)`：以 `(l,G)` 保存弦身份、匿名无序端点对与给定中点，不创建M/A/B、端点坐标或根。重复事实合并来源；同一弦的矛盾中点拒绝。

`Expression(l)` 复用 NamedLineQuery，仅定位并读取该直线唯一已有方程；初态没有线方程时返回None，不求参、不推导。多个方程仍按既有查询规则返回未定，不新增多方程消歧。

ID4795的G为 `x²/4+y²/16=1`，RM4提交y轴框架、a²=16、b²=4。RM40按实际x/y分母d_x=4、d_y=16计算：

- ρ=m_x²/d_x+m_y²/d_y=1/8；0<ρ<1，允许唯一非退化中点弦。
- 法向量 `(m_x/d_x,m_y/d_y)=(1/8,1/16)`。
- 直线为法向量与 `(x-m_x,y-m_y)` 点积等于0；提交规范化表达式 `x+y/2-1`，等价于 `2x+y-2=0`。

不除以中点横坐标，故支持竖直／水平弦。ρ=0返回undetermined，ρ≥1返回conflict。RM40不依赖RM54/RM45，也不生成端点坐标和。已有线方程必须为数值非退化一次式且与结果等价，保留原式，不覆盖；失败不提交部分结果。
