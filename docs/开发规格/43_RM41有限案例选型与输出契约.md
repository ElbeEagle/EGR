- 输入：已提交的IntersectionReduction，绑定curve、line、两个方程ID及relation_id；沿用该记录的主变量和坐标回代关系，不另建根对。

- 原查询ChordLengthQuery与只读答案逻辑复用。不存在直线／弦长的否定答案不在本批契约内，失败不等于已解。
