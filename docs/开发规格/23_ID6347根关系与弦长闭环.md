# ID 6347 根关系与弦长闭环

日期：2026-10-03。数值标准抛物线与独立直线；固定回放，不是自主模型选择。

## 本批结果与职责

原始 facts/query 经 RM78→RM42→RM43→RM50 得到弦长 8。RM78 输出 y²−4y−4=0 与 t→(t+1,t)；RM42 提出根和 4，RM43 提出根积 −4，两步均记录 Δ=32、不同实根数 2；RM50 消费上述已提交结果，计算 √[2×(4²−4×(−4))]=8。RM43 与 RM42 可交换顺序。

代数关系与几何资格分开保存：二次方程的根和积不要求两实根；Δ=0／Δ<0 分别记录不同实根数 1／0，但 RM50 返回 inapplicable，不输出零长普通弦或复数长度。一次消元式不能应用二次韦达。缺少前提不补做推导；匿名根不生成命名点，不放入互斥赋值 candidates。

## 核心定义

| 定义 | 含义、操作与后续用途 |
| --- | --- |
| quadratic_coefficients | 检查输入是一元数值二次式，返回 a,b,c，供根关系与一致性检查使用 |
| quadratic_root_relation | 按请求计算 −b/a 或 c/a，返回单个根和／积；供 RM42／RM43 提案使用 |
| classify_quadratic_roots / QuadraticRootStatus | 前者计算判别式并判定不同实根数；后者只保存这两个结果，供提案记录及 RM50 资格判断使用 |
| chord_length_from_relations | 输入已知 S、P 与坐标映射 (αt+β,γt+δ)，返回 √[(α²+γ²)(S²−4P)]；不执行韦达或解方程 |
| derive_root_relation | 读取绑定消元事实，提出本模型负责的根关系，以及独立的判别式／实根数属性，由应用器提交 |
| derive_chord_length | 读取同一事实下已提交的 S、P、Δ 与实根数，核验与源多项式一致、存在两个不同实交点，再提出弦长；缺属性即停止 |
| properties[(消元事实ID, 属性名)] | 沿用现有状态字典；新增 root_sum、root_product、discriminant、distinct_real_roots、chord_length，避免不同直线或方程对串用结果 |
| ChordLengthQuery(line,curve) | 只表示“求这条直线被这条抛物线截得的弦长”，不判交点、不计算长度；解析 Length(InterceptChord(H,G)) 时建立 |
| check_binding / enumerate_actions | 前者核验 relation_id 指向动作所绑定的消元事实；后者从已有消元事实生成结构候选，不保证数学前提成立 |
| extract_answer / solve_chord_length_slice | 前者按唯一方程对读取已提交弦长，缺失／歧义返回 None；后者固定组织四步执行并返回结果与轨迹，不负责模型预测 |

RM42/43/50 动作复用 curve/equation_id/line/line_equation_id，relation_id 指定 IntersectionReduction.fact_id；其他绑定字段留空。沿用属性 delta 与来源链，无新增命名根或点状态。RM50 的一致性检查仅核验已有数据，不补齐缺失根关系。
