# RM19／RM20通径有限案例契约

日期：2026-11-20。本批仅选型和独立核验，尚未接入运行时。

## 选择依据与案例

对照职责表与原模型定义，RM19计算双曲线通径2b²/a，RM20计算抛物线通径2p。两者共享“弦属于指定曲线、经过其焦点、垂直于轴”的资格关联；不需要扩大其他曲线消元。

| 案例 | 原始输入重点 | 输出及决定 |
|---|---|---|
| 6057 | 双曲线x²/3−y²/4=1；线段L为弦；过Focus(G)；垂直xAxis | 首批RM5→RM19，Length(L)=8√3/3 |
| 6770 | 抛物线y²=4x；线段L为弦；过Focus(G)；垂直SymmetryAxis(G) | 首批RM7→RM20，Length(L)=4；原标签19不适用，保留标签并另记执行链 |
| 598 | 数值抛物线、焦点别名F、直线倾角π/2及命名端点 | 延后倾角到方向的资格转换及线段表达式查询 |
| 1378 | 抛物线通径为圆直径，查询圆被y轴截弦 | RM20仅子步骤；圆对象和截弦链后置，不当作原题已解 |

RM18短候选2976／1509涉及最短焦点弦，需另有最值资格，不能只算2b²/a便声称完成最值推理。本批优先19／20。

## 输入与前提（待实现）

- 复用SegmentChord的segment、内部line、curve及来源；仅为RM20扩展声明Parabola的IsChordOf入口，不开放抛物线给定中点事实语法。
- 有限解析PointOnCurve(Focus(G),L)和IsPerpendicular(L,xAxis/yAxis/SymmetryAxis(G))，允许这两类关系末尾=True，不做任意布尔语法泛化。保存原始事实ID及曲线／线段绑定；重复同义事实合并来源，错曲线、未声明对象、矛盾方向不能静默处理。
- RM19要求已提交同一双曲线标准参数a²,b²>0及实轴框架；垂直坐标轴必须正是该实轴。两焦点通径长度相同，Focus(G)在此仅表示该曲线某一焦点，不据此构造唯一焦点坐标。
- RM20要求已提交p>0及开口轴。p为正几何参数，原式负号归方向；SymmetryAxis必须属于同一曲线。首版可按四方向组织诊断，真实首题只验证向右。
- 缺弦身份、焦点归属、垂直条件、标准参数或来源不可应用；未知符号／方向未定。不能把任意焦点弦或任意垂直弦当通径。

## 计算、提案、提交与查询（待实现）

公共计算在资格通过后返回正长度：RM19为2b²/sqrt(a²)，RM20为2p。模型提案读取弦、焦点、垂直关系及参数来源，提出弦身份键下chord_length；应用器沿用原子属性提交、重复幂等和冲突回滚。

Length(L)建议新增有限线段长度查询，按SegmentChord定位唯一弦并只读已提交长度。不要与消元记录键下的chord_length混用；没有结果不补公式，不给出否定答案。不要求RM33／RM41／RM50，也不构造端点。

独立审查中计算焦点并求交仅作为交叉核验，不是拟议运行链的隐藏前置。过焦点且垂直轴的标准非退化圆锥曲线保证两个不同实端点；证明依赖上述完整资格，不能复用任意直线求交资格。
