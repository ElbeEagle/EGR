## 案例与路径

ID 6347 原始事实为 G: Parabola、H: Line、y²=4x、y=x−1，查询 `Length(InterceptChord(H,G))`。没有给出命名交点；查询不能直接证明两交点存在。

采用 x=y+1，代入得到 y²−4y−4=0。数学上 Δ=32>0，两根和 S=4、积 P=−4；点的还原映射为 t→(t+1,t)。弦长²=(1²+1)×(S²−4P)=64，故长度为 8。这是后续链的数学核验；本批执行器只完成 RM78。

原 process 走焦点弦长路径，models=[7,78,42,51] 与该推导不完全对应。保留弱标注；一般弦长计划路径为 RM78→RM42/RM43→RM50，实交点资格检查嵌入消费几何根对的公共操作。RM7 不作为直接多项式代入的必要前置。RM51 留给已知两点坐标差的路径，不为匹配标签强行使用。

ID 56 则需要由过点 M 的未知直线构造 x=ty+1、建立命名 A/B 与根的关联，并处理斜率约束与非零分母；当前数值模式不覆盖。待 6347 的匿名交点对链完成后再推进，避免同时引入符号参数与命名点关联。

## 模型与对象契约

| 环节 | 输入 → 输出 | 边界／状态 |
| --- | --- | --- |
| RM78 substitute_line | 显式绑定的标准抛物线与独立直线方程 → IntersectionReduction | **已实现**：数值系数、四方向、原点顶点；输出代数消元关系，不求根／弦长 |

| 查询 | Length(InterceptChord(H,G)) → 已提交弦长 | **待实现**：只读精确曲线／直线及方程绑定；缺结果返回未定，不在读取时消元 |

根对默认无序。若未来生成坐标，两个坐标必须分别由同一个根 t 还原，不能独立排序 x/y 后配对。匿名根不得任意命名为 A/B；有命名交点声明时先记录集合对应，只有额外方向／坐标条件能区分标签时才定向。多根作为同一交点集合的元素，不应塞入当前 `Proposal.candidates` 的“互斥标量赋值分支”通道。

## 本批实现

- 公共操作 `substitute_line_in_parabola(curve,line,x,y)`：验证有限实数系数、标准抛物线与非退化仿射直线；优先 x=my+n，以 y 为变量，水平线改为 y=常数、以 x 为变量。代入后保存首一的一次或二次多项式，不以数值解或判别式替代原关系。
- `IntersectionReduction` 保存 fact_id、curve/line、两项 equation_id、variable、xy 还原映射、polynomial、source。稳定 ID 为 `derived:intersection:{curve_equation_id}:{line_equation_id}`，以方程对隔离同曲线不同直线。
- RM78 的 `BoundAction` 复用 curve/equation_id/line/line_equation_id；其他绑定字段留空。`Proposal.intersection_reductions` 经应用器原子提交至同名状态字典，并写入 delta、来源、revision/history。重复 no_op、已有不同输出 conflict；不改写原方程、不生成点实体。
- 未定参数返回 undetermined；非线性／退化直线、非标准抛物线等返回 inapplicable。已提交 values 可先回代并记来源；不求新参数。输出仅含数值系数，无待未来赋值的符号系数，因此本批不扩展受限归约机制。
- 旧 RM78 can_apply/apply 保留；新模式不依赖旧实现中的字符串占位关系。尚未增加原始弦长查询解析或固定求解入口。
