## 📋 我的项目理解

### 1️⃣ **项目核心目标**

这是一个**基于最大熵原理的数学推理系统 (EGR)**，目标是在 **Conic10K** 数据集（圆锥曲线问题）上实现 **60-80%** 的准确率。

**核心创新**：将最大熵原理系统化应用于自动数学推理，通过三层最大熵原理实现：
1. **策略学习**：P(Y|X) - 模型选择概率
2. **路径规划**：信息增益最大化（熵减少）
3. **置信加权**：预测不确定性惩罚

---

### 2️⃣ **双层状态表示机制**

这是系统的核心设计，我认为非常精妙：

#### **SymbolicState（符号状态）** - 细粒度
```python
{
    "entities": {"G": "Hyperbola", "m": "Number"},
    "equations": ["Expression(G) = (x^2/4 - y^2/m^2 = 1)"],
    "parameters": {"a": "2", "b": "m", "a^2": "4"},
    "geometric_relations": ["渐近线: y = ±(m/2)x"],
    "coordinates": {"F": ("c", 0)},
    "constraints": ["m>0"]
}
```
- **用途**：精确推理和模型应用
- **特点**：完整的符号信息，模型直接修改它
- **原则**：只增不减，信息单向累积

#### **AbstractState（抽象状态）** - 粗粒度
```python
{
    "curve_type": CurveType.HYPERBOLA,
    "query_type": QueryType.VALUE,
    "has_equation": True,
    "has_parameters": {"a", "b"},
    "completeness_score": 0.65,  # 完整度评分
    "reasoning_depth": 0
}
```
- **用途**：神经网络输入、状态索引
- **特点**：有限离散的特征空间（~40万种状态）
- **关系**：从 SymbolicState 重新构建，不修改

**为什么需要两层？**
- SymbolicState 无限，无法训练神经网络
- AbstractState 丢失细节，无法精确推理
- **两层互补，缺一不可**

---

### 3️⃣ **模型库（80个定理模型）**

每个模型代表一个数学定理，例如：
- **Model 5**: 双曲线标准方程参数提取 `x^2/4 - y^2/m^2 = 1 → a=2, b=m`
- **Model 21**: 双曲线渐近线公式 `渐近线: y = ±(b/a)x`
- **Model 41**: 韦达定理 `x1+x2=-B/A, x1*x2=C/A`

**标准接口**：
```python
class TheoremModel:
    def can_apply(self, state: SymbolicState) -> bool:
        """检查前置条件"""
        
    def apply(self, state: SymbolicState) -> None:
        """直接修改state，添加新信息"""
```

**关键原则**：
- ✅ 只增不减（只能添加信息）
- ✅ 幂等性（重复应用不出错）
- ✅ 无副作用

---

### 4️⃣ **数据流程**

从数据集中的一个样本（ID=2）理解完整流程：

```json
{
    "fact_expressions": "G: Hyperbola;m>0;Expression(G) = (x^2/4 - y^2/m^2 = 1);...",
    "query_expressions": "m",
    "models": [5, 21],  // 解题步骤：模型5 → 模型21
    "answer_expressions": "5"
}
```

**推理过程**：
1. **S0（初始状态）**：解析 fact_expressions
   - SymbolicState: `{entities: {G: Hyperbola}, equations: [...], ...}`
   - AbstractState: `{curve_type: HYPERBOLA, has_equation: True, ...}`

2. **应用 Model 5**（标准方程参数提取）
   - 输入：`Expression(G) = (x^2/4 - y^2/m^2 = 1)`
   - 输出：`parameters["a"] = "2", parameters["b"] = "m"`
   - 新的 completeness_score: 0.3 → 0.5

3. **应用 Model 21**（渐近线公式）
   - 输入：`a=2, b=m`
   - 输出：`渐近线方程 y = ±(m/2)x`
   - 结合题目条件 `5x-2y=0`，推导出 `m=5`

## 🤔 我的几个技术思考

### 1. **关于符号计算**
文档建议保持符号形式，例如 `c = "sqrt(a^2 + b^2)"`，而不是立即数值化。这样做的好处：
- ✅ 保留完整推理链
- ✅ 支持后续符号变换
- ✅ 便于调试

但我会在必要时尝试简化（如 `a^2=4 → a=2`）

### 2. **关于 completeness_score**
这是启发式评分，不是精确的。我计划：
- 初期使用文档的规则（方程+0.3，参数+0.1等）
- 后期可能基于数据统计优化

### 3. **关于模型应用顺序**
数据中的 `models` 字段提供了正确的应用顺序，这是金标准。我会：
- 先验证能否正确执行这些序列
- 再考虑神经网络预测模型选择
