# ID7439：线段弦对象与所在直线查询

日期：2026-10-19。接续[规格37](37_命名端点中点弦实现.md)。本批选择ID7439，新增输入身份支持，复用RM3、RM40、RM54、RM45；命名中点别名及RM46另批。

## 输入与职责

接受已声明H:LineSegment、G:Ellipse、IsChordOf(H,G)（也接受= True）及数值Coordinate(MidPoint(H))。H仍是线段；内部@overlap:H表示其所在直线，是对象身份而非已知方程。以该直线和G创建既有弦／匿名端点对，分别保留弦声明与中点来源。

先收集弦关系再处理中点，支持重排、后置声明和重复来源合并。同一线段多曲线关联、矛盾中点、错误声明拒绝；不同线段不会因同属一条椭圆被合并。首批不关联用户命名直线，不支持OverlappingLine(H,l)或MidPoint(H)=M，也不识别线段端点别名。

Expression(OverlappingLine(H))复用NamedLineQuery，只定位该内部直线并读取已提交方程。初态无答案、无端点坐标、无派生方程。RM40／45仍负责资格与直线提案，RM54仍只提出端点和，原应用器负责提交。

- `src/state/segment_chord_facts.py`（新增）→ 有限线段输入关联。SegmentChord保存segment、line、curve及IsChordOf来源；collect_segment_chords两遍收集关系／中点，创建内部直线身份，返回已处理事实位置供主解析跳过，不做几何计算。

- `src/theorems/midpoint_proposals.py` → 绑定提案。扩展check_midpoint_binding，校验线段类型、内部直线、曲线及关系来源；允许来源为中点与身份声明并集，丢失／错绑关系则拒绝。公共计算和状态提交未新增。
