## 已实现

- RM11/RM12 共用 `parameter_proposals.py`：`derive_a_sq / derive_b_sq / derive_c_sq` 消费同一对象的另两个平方参数，按椭圆 a²=b²+c²、双曲线 c²=a²+b² 补齐目标；零／负值或冲突拒绝，正值条件未确定时不提交。
- `constrain_parameters` 消费三个已有参数表达式，求标量查询并筛选正值条件；保留多根，不默认取正根。不要求依赖共焦点关系。

- 应用器新增方程提案：与属性等共同提交、按稳定派生 ID 去重；后续已知值同时归约派生方程，原题方程保留。
- 查询 `Expression(Asymptote(G))` 读取已生成的完整方程对；初始化和答案读取均不推导渐近线。

## 边界与后续

- 普通参数模式消费 `properties[(curve, a_sq/b_sq/c_sq)]`；未新增长度／焦距自然语言事实解析或参数到完整曲线方程的构造。
- 无曲线方程时可仅绑定对象。有方程时必须明确绑定并消费此前建立的标准框架，不能省略绑定以跳过一致性检查。
- 正向渐近线和当前方程框架仍限原点中心、x 轴焦向；其他方向、平移、旋转待扩展。去重针对稳定 ID，不是任意等价方程的全局合并。
- 参数约束求解仍限一元至多二次，未接入选择器、通用分支搜索或最终训练 schema。旧 v1/v2 trace 作为历史证据保留。

下一批建议以 y 轴案例补 RM4/RM6，并扩展框架和渐近线方向，复用普通参数关系模式。
