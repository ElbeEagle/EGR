# Theorems V2 第二批执行器与裸测报告

## 1. 本批范围

本批在旧定理代码完全不变的前提下，将 V2 定理库从 17 个 concrete executor 扩展到 35 个；80 个模型均保留规范描述，尚未实现的模型继续返回 `SPECIFICATION_ONLY`，避免伪执行。

新增模型 ID：

- 离心率范围：14、15
- 焦半径：16、17
- 通径：18、19、20
- 双曲线焦点到渐近线距离、共渐近线系、等轴双曲线：22、23、24
- 圆锥曲线第二定义：25、26
- 准线：27、28
- 椭圆焦点三角形周长：32
- 参数方程与切线：37、38、39

选择原则不是单纯按频率排序，而是优先实现能由现有圆锥曲线 typed facts 支撑、可以组成连续推理链的模型。Vieta、坐标变换、直线交点和向量模型虽然频率更高，但当前信息空间缺少稳定的二次方程根、交点、多项式和向量表示，过早 concrete 化会制造大量表面匹配。

## 2. 信息空间与纠错调整

`ExpandedRawFactAdapter` 新增了以下原始事实映射：焦点集合、离心率、焦距、焦点所在坐标轴、斜率、点坐标、中点、渐近线表达式，以及单圆锥曲线场景中的 `a/b/c/e/p` 简单赋值。

序列纠错新增或收紧了：

- 方向模型 3-10 的候选替换；
- 依赖步骤前移；
- 仅在依赖定理真实返回 `APPLIED` 时插入依赖，避免根据唯一 match 过度补链；
- 修复建议输出为独立 JSONL，不覆盖训练数据。

## 3. 裸测方法

数据：`data/train_with_models_v2.json` 中 5,355 道同时含定理序列与文字过程的样本，共 20,212 个原始步骤。

命令：

```powershell
python scripts/theorems_v2/evaluate_expanded_apply.py `
  --input data/train_with_models_v2.json `
  --summary-output outputs/theorems_v2/expanded_apply_summary.json `
  --repairs-output outputs/theorems_v2/sequence_repairs.jsonl
```

`bare` 严格按训练数据中的原始模型顺序执行，不补步骤、不换方向模型。`corrected` 允许依赖前移、可验证的依赖插入和方向模型替换，用于估计当前 applicator 在辅助模式下的上限，不应与裸准确率混报。

## 4. 结果

| 指标 | 第一批 17 concrete | 第二批 35 concrete |
| --- | ---: | ---: |
| `APPLIED` 步数 | 3,269 | 3,559 |
| `SPECIFICATION_ONLY` 步数 | 8,017 | 6,771 |
| 全步骤裸 apply 率 | 16.17% | 17.61% |
| concrete 步骤裸 apply 率 | 26.81% | 26.48% |
| 裸序列完整跑通题目 | 237 (4.43%) | 276 (5.15%) |

第二批纠错/辅助结果：

- `APPLIED` 4,462，`ALREADY_KNOWN` 232；
- 完整跑通 461 / 5,355，比例 8.61%；
- 依赖前移 519 次、可验证依赖插入 249 次、方向模型替换 507 次；
- 生成 1,232 条待审核序列修复记录；
- 原始事实仍有 9,883 个 atom 未解析，适配错误 47 个。

concrete 步骤裸 apply 率轻微下降并非回归：本批把一批原本不进入分母的困难模型从 specification-only 提升为真实执行，因此暴露了更多信息缺口。全步骤覆盖、成功步数和完整题目数均上升。

## 5. 判断与下一步

目前首要瓶颈已经从“圆锥曲线基础性质没有 executor”转为“题面信息无法稳定进入 typed state”。下一批不宜直接铺满剩余 45 个 executor，建议先完成四组信息结构：

1. 二次方程、多项式系数与根集合，随后实现 Vieta 41-43 和代入消元 78；
2. 直线标准式、交点和距离，随后实现 46-55、72；
3. 向量、内积、共线和线性组合，随后实现 56-63；
4. 统一代数等价与条件分支记录，降低 `NO_MATCH` 并使纠错证据可审计。

训练定理序列可以调整，但只应采纳执行器能验证的修改。`outputs/theorems_v2/sequence_repairs.jsonl` 是候选修复集，建议按操作类型和高频模型分层抽样审核，再生成带版本号的新训练集，而不是原地修改源数据。
