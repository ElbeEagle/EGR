## 给定中点如何绑定弦和端点

以下为拟议结构语义，名称不是已注册类或字段：

| 概念 | 保存内容与后续用途 |
| --- | --- |
| 弦身份 | 由有序角色(line=l, curve=G)确定；附原事实ID。它代表该直线被该曲线截得的弦，不把l当线段 |
| 中点事实 | 引用上述弦身份，保存给定坐标与来源；保留为复合对象，不伪造题中未声明的点名M，也不声明它在椭圆上 |
| 匿名无序端点对 | 绑定同一弦身份，记录“两个不同有限实交点”的给定语义及来源；不生成点坐标、根序、局部坐标变量或用户点名A/B |
| 端点和关系 | 若执行RM54，按该端点对保存x_sum=2m_x、y_sum=2m_y，供RM45读取；不是单个端点坐标 |
| 几何资格 | 区分题目给定弦语义与计算核验；模型检查标准椭圆、内点条件及非中心条件，不能仅凭身份标记跳过矛盾 |

同一l与不同G是不同弦；同一G与不同l也不同。重复中点事实保留来源并一致性核对，矛盾坐标拒绝。若以后给出Intersection(l,G)={A,B}，只能把这组无序点名关联到同一弦对，不能按A/B顺序分配根。现有命名交点解析限抛物线，椭圆关联须另行扩展，首批4795不依赖它。

若已有l方程，后续模型必须核对它通过给定中点并满足方向／两交点资格，不能覆盖或忽略；若已有端点坐标，还需检查归属、不同性和中点一致。不能完成该核验时应未定，不能先提交结论。

## 无除法关系与退化检查

设实际x/y分母为D_x,D_y（均正），中点M=(m_x,m_y)，令ρ=m_x²/D_x+m_y²/D_y。使用

    n=(m_x/D_x,m_y/D_y),  n·d=0,
    (m_x/D_x)(x−m_x)+(m_y/D_y)(y−m_y)=0。

RM45路径先由点差得到(S_x/D_x)Δx+(S_y/D_y)Δy=0，再使用既有坐标和。无需除以Δx、m_x或m_y，轴上中点自然覆盖竖直／水平弦。

- 0<ρ<1：非中心内点，n非零，唯一非退化弦方向；关于M的直线参数代入消去一次项，得到两个相反且非零的参数，故中点身份成立。
- ρ=0：中心点，所有过中心直径均可；输出undetermined，不提交0=0作为直线，不任选斜率。
- ρ=1：只能退化为切点，违背两个不同交点；ρ>1：不能是椭圆实弦中点。两者应conflict，不能套用切线公式冒充弦。

ID4795：D_x=4,D_y=16，ρ=1/8；直线2x+y−2=0。独立求交得到((1−√7)/2,1+√7)、((1+√7)/2,1−√7)，均在椭圆上且中点正确。这是审查核验，不在运行时提前生成端点。

ID7439数学上得x+2y−3=0，但原输入涉及LineSegment、IsChordOf与OverlappingLine，首批延期；不能把改写成4795语法的投影说成原题已解。ID269含双焦点／垂直／多弦关系，不选为首批。
