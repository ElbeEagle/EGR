# ID6347 焦点弦长路径（RM33）

日期：2026-10-05。完成已有 TODO 的独立固定路径，不替换一般弦长路径，不代表自主模型选择。

## 职责与运行结果

RM33 必须消费已提交且与曲线匹配的标准框架、p 与焦点坐标，同一方程对的消元结果，以及 RM42 已提交的根和／判别式／两实根资格。执行时将焦点代入所绑定直线，残差必须为零；这是 RM33 的适用前提核验，写入操作记录，不另要求选择器预测一个模型。不是根据题目关键词或查询推定“焦点弦”。

RM33 不提取缺失标准参数、不重新消元或执行韦达，也不输出 RM34/35 的根积性质。旧 model_033.py 的无绑定实现保留；新绑定路径采用这里的职责。

ID6347 路径为 RM7→RM78→RM42→RM33：RM7 提交 p=2、F=(1,0)；RM78 给出 y²−4y−4=0、x=y+1；RM42 提交 y₁+y₂=4 与 Δ=32、不同实根数2；RM33 核验 F 在线 y=x−1 上，转换得 x₁+x₂=6，再算 6+p=8。没有执行 RM43。

四方向统一使用长度=sign×轴向坐标和+p，p>0。若轴向坐标映射为 αt+β，则由已有根和 S 得轴向坐标和 αS+2β，不求根或根积。支持原点顶点的四方向数值标准抛物线、独立直线和仿射坐标还原。通过焦点但平行轴、只有一个有限交点的直线不能当作普通焦点弦。
