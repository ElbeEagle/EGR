# ID56 符号韦达与斜率求参闭环

日期：2026-10-04。原始 facts/query 经固定 RM78→RM42→RM43→RM55，得到 x+y/2−1=0，即 2x+y−2=0。不是自主模型选择；不使用 process、models 或参考答案作为求解输入。

## 状态转换与边界

1. RM78 提交局部参数 u、直线 x=uy+1、消元 y²−2uy−2=0 及无序命名根对。
2. RM42 提出根和 S=2u；RM43 提出根积 P=−2。两步记录判别式及两实根资格，可交换顺序。
3. RM55 读取同一根对的 S/P、资格、曲线及原点坐标。由 P≠0 和 y²=cx（本题 c=2），得到 x_A x_B=P²/c²≠0，两个斜率分母均非零，才允许斜率和=cS/P。结合给定值 1，求得唯一可行 u=−1/2。
4. 同一提交事务将直线归约为 x+y/2−1=0，根和归约为 −1，消元式归约为 y²+y−2=0，坐标映射归约为 (1−y/2,y)。局部参数记录保留符号身份，数值存于 values；命名根标签与来源不变。
5. NamedLineQuery 仍只读已提交直线；不执行求参或回代。

符号模式仅接受已登记局部实参数、有限实系数表达式和非零数值二次首项；未登记自由符号／符号首项不接收。数值模式默认边界保持不变。实根资格可利用给定两交点转译的 Δ>0 条件，读取来源一并记录。

RM55 首版限 x 轴标准抛物线、同一起点坐标为 (0,0)、已建立命名根关联及一个局部待求参数。缺 S/P 不补做韦达；P 非零不能证明时不先约分；非原点起点不支持。已有结果不一致 conflict，缺前提 inapplicable，未定／多候选不任意选择。未知参数求解复用至多二次的有限实根筛选，相关条件必须成立。
