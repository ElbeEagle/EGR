## 输入与职责

限中心在原点、轴与坐标轴一致的数值双曲线。输入支持复合中点、声明线段及命名端点中点；复用已给坐标的别名快照与来源核验，不求端点。RM54只提出同一无序对的 x_sum、y_sum；RM46读取已提交标准参数／轴向和两项坐标和，核验中点一致性后提出直线。RM54可先于标准模型执行，RM46不能省略这些前提。

## 独立实弦资格

写成 αx²+βy²=1，αβ<0。x轴双曲线取(1/a²,−1/b²)，y轴取(−1/b²,1/a²)，不能把两个系数都当正数。
令 M=(m_x,m_y)、q=αm_x²+βm_y²。点差法向量为(αm_x,βm_y)，候选线经过M；沿 v=(−βm_y,αm_x) 代入得到 αβq·t²+q−1=0。

| 条件 | 处理 |
|---|---|
| q<0 或 q>1 | 判别式正，两个不同实交点，允许提交 |
| 0<q<1 | 无实交点，conflict |
| q=1 | 切触重根，conflict |
| 非中心且q=0 | 二次项消失、常数非零，无交点，conflict |
| M=(0,0) | 方向不能唯一确定，undetermined |

公共操作不调用椭圆内点判断。成功提案保存 midpoint_q、intersection_discriminant、normal_x/y、distinct_real_intersections=2；沿用属性来源与派生线提交。不使用椭圆的midpoint_rho字段。已有直线及数值端点继续执行一致性核验；失败不提交部分结果。
