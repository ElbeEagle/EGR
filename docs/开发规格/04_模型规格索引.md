## 阅读方法

- “输入→输出”表示数学职责及所需事实。依赖的是事实，不强制依赖某个前置模型 ID；同一事实可以由题目直接给出或由不同合法路径得到。
- 操作代号是拟议公共能力，不是现有 API。所有模型共同需要绑定、delta、来源、去重与失败处理，表中不重复列出。
- “题数／候选题”来自 v3 原始 `models`：每题每 ID 去重计数，候选取文件中首个包含该 ID 的原题。它们只是后续阅读入口，**未逐题核验，不能证明模型用途正确**。
- 表中 80/80 仅表示职责条目齐全。当前只对 ID 2、5、9、51、56 五道题整理数学案例；本批没有验证全部模型代码。

| 操作代号 | 共享能力 |
| --- | --- |
| N | 标准形式识别、系数与方向处理 |
| R | 已给关系的类型化实例化，具有显式适用条件 |
| A | 精确代入、化简、声明范围内求解与受限归约 |
| D | 定义域、非退化、分支、解集筛选与结果检查 |
| G | 点线坐标与几何量的数值／符号计算 |
| P | 多项式系数、消元、根关系与配方等计算 |
| T | 三角表达式计算和角度条件处理 |
| I | 不等式、区间、界与取等可达性处理 |
| V | 向量分量、行列式和点积计算 |
| W | 受约束参数化／实例构造，记录新符号或构造选择 |

公共能力可以被不同模型复用，但不能因此隐藏另一项高层推理：例如 RM55 只能消费已建立的韦达关系；RM76 自身声明距离公式计算和相切关系，不要求把每个数值距离计算都单独计为 RM52。哪些几何关系是输入、哪些由当前模型引入，必须在细分模式中写明。

## 定义校核与待细化项

不直接修改原模型说明，先记录后续实现应遵守的条件：

1. **RM34**：沿用库内 y²=2px，焦点为 (p/2,0)。焦点弦写作 x=my+p/2，消元得 y²−2pmy−p²=0，所以 y₁y₂=−p²，x₁x₂=(y₁y₂)²/(4p²)=p²/4。**原说明的 p²/4 正确**，实现须与标准式的参数约定一致。
2. **RM39**：同一约定下，切线为 yy₀=p(x+x₀)，不是 2p(x+x₀)。把切点代回即可检验因子；顶点切线 x=0 也需支持。
3. **RM58**：一般三角形面积是二阶坐标差行列式绝对值的一半；原说明的二点公式仅适用于第三个顶点是原点。
4. **RM65–67**：判别式先对应非退化的一元二次方程，再在消元保持等价时解释为交点数；不能跳过几何与代数对象关联。
5. **RM41/42/43、44/45/46、50/51**：保留多个 ID 以兼容模型库，但共用底层实现；内容等价时按事实去重，不强制串联执行。
