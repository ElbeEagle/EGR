## 执行结果与边界

原始 ID56 输入经 RM78 `parameterize_named_line`，一次提交：局部实参数 u、派生直线 x=uy+1、消元式 y²−2uy−2=0、无序根集合对应 {A.y,B.y} 及两不同实根的要求。答案仍为 None，不创建 A/B 坐标、不求 u、不消费斜率和。

首批限原点顶点、x 轴向的数值标准抛物线 y²=cx（c≠0）和有限数值过点。水平分支 y=y_M 代入后必须确认为非退化一次式，因此只有一个交点，与给定的两个不同交点不符；记录这一排除证据后，采用 x=u(y−y_M)+x_M。竖直方向 u=0 被保留。y 轴向、平移、未知系数暂不支持，不能由本批推断所有直线族都能排除水平分支。

给定 NamedIntersection 提供两不同交点要求，RM78 将其译为消元式 Δ>0 的约束并记录来源；不是求出根或提前执行韦达。ID56 的 Δ=4u²+8 自动为正；过顶点的变体则保留 u≠0 所对应的判别式条件。

## 核心定义

| 定义 | 操作或保存内容、供谁使用 |
| --- | --- |
| parameterize_through_point | 接收曲线、数值点和指定实参数，返回 LineSubstitution 及水平分支的一次式；供 RM78 提案包装输出 |
| parameterize_named_line | 核验绑定，分配稳定局部参数，调用公共计算，提出派生直线、符号消元、无序根关联及 Δ>0 要求，交应用器统一提交 |
| LineParameterization / parameterizations | 保存直线、局部参数、过点与坐标／归属／交点来源 ID、派生直线 ID；供重复执行复用与后续求参定位 |
| IntersectionReduction.named_points / intersection_id | 保存无序点标签及原交点声明 ID；结合已有 variable、xy 表达 {A.y,B.y} 为根集合和逐点坐标还原映射，供符号韦达与 RM55 使用，不分配根大小 |
| BoundAction.incidence_id | 显式选择“指定点在指定直线上”的事实；relation_id 同时选择命名交点声明，coordinate_id 选择过点坐标，避免来源混用 |
| Proposal.parameterizations | 仅保存待提交参数记录；由 BoundApplicator.apply 与其他增量一起提交到 state.parameterizations |
| check_binding / enumerate_actions / apply | 分别检查源事实一致、列出结构候选、执行事务；新增派生直线的 owner 是直线，不是曲线 |

参数使用保留命名空间 `@parameter:{line}:u`，不进入原题声明符号表，也不覆盖用户 u/m/t。同一直线重放使用同一 Symbol，不同直线隔离。首批一次绑定一个过点表示；同直线不同参数化来源不静默合并。另有独立直线方程时不替代它；已有不一致输出 conflict，整步回滚。

派生直线 ID 为 `derived:{line}:parameterized`；消元记录沿用方程对 ID。查询读到含局部参数的直线仍返回 None。未来求参后的消元记录归约与一致性校验尚待扩展，不将已有方程归约机制等同于整个新结构已完成归约支持。
