# RM73→RM52派生直线距离实现

日期：2026-11-27，承接[规格63](63_RM73_RM52派生直线距离消费契约.md)。

## 文件与核心职责

- `src/state/named_distance_evidence.py` → 新增距离依赖证据。DistanceSnapshot保存点／线／坐标／方程ID、依赖摘要及距离值；distance_inputs核验唯一新鲜RM73直线与数值目标坐标；make_distance_snapshot组织证据，read_named_distance只核对来源、快照和结果，不计算距离。
- `src/state/transition_state.py` → 扩展复合查询及证据容器。Distance(P,LineOf(A,B))复用无序直线身份和PointLineDistanceQuery；distance_snapshots保存已提交证据，相关距离读取经新鲜度检查，初态／过期返回None。
- `src/theorems/distance_proposals.py` → 扩展RM52消费提案。计算前核验派生线和目标来源，提出距离及匹配证据；已有数值缺证据或依赖过期拒绝补造，数值冲突拒绝，旧显式线／准线分支不变。
- `src/theorems/bound_application.py` → 扩展事务提交。Proposal增加distance_snapshots；应用器核对模型、绑定键、提案数值与当前依赖摘要，将证据和距离一起写入delta及状态，重复幂等、冲突回滚。
- `tests/test_bound_named_distance.py` → 新增21项测试。覆盖两题原始诊断查询、反序重排、点在线上为零、竖线／缩放、旧点／旧线／缺证据、多线歧义、隔离及回滚。

## 入口、依赖与提交

Distance(P,LineOf(A,B))登记已有无序NamedLine身份，再用PointLineDistanceQuery定位；A/B必须为不同声明点，P可为端点。解析只建立身份，无直线时无距离结果。RM73和RM52仍分别由绑定动作执行，不在查询中推导。

首批保护范围为NamedLine身份或可识别的RM73派生方程；只有唯一有效RM73输出可用于该路径。命名身份下其他来源等价方程不会被自动升级，返回不可应用／未完成。RM52核验目标坐标来源、有限实数及fresh_two_point_line；方程ID／owner／role与身份必须一致。

DistanceSnapshot是不可变证据记录，以既有(owner,distance_key)为映射键。摘要包含目标坐标及来源、规范线方程、RM73来源摘要、线来源和代入值；value关联提交距离。其line／point／coordinate_id／line_equation_id便于追溯。快照只比较依赖，不在读取中调用距离公式。线规范化允许非零比例缩放；全部state.values参与摘要，采用保守失效。

Proposal与状态各增加证据映射；原应用器先验证证据与当前输入／距离一致，再和数值同事务提交，并记录distance_snapshots delta。旧数值缺证据不自动补齐；任一冲突不产生部分写入。若目标点改变，或重新生成了同身份新线，旧距离证据不匹配仍拒读。既有显式线、准线别名和Focus(G)路径未改为新协议，不宣称全库依赖检查已统一。
