# 命名端点中点别名实现

日期：2026-10-22。接续[规格40](40_线段命名中点别名实现.md)，完成2290／4761；RM46仍按[独立实弦契约](39_命名中点别名与RM46资格审查.md)另批实现。

## 身份与来源

MidPoint(LineSegmentOf(A,B))=M通过已给椭圆Intersection(l,G)={A,B}定位唯一弦。A/B排序为无序对；不创建新的线段实体或端点坐标，也不把M视为端点。声明后置、事实重排、交点参数反转、端点反序均支持。

扩展现有ChordMidpointAlias：声明线段模式保留segment；命名端点模式segment=None，并保存pair_id与endpoints快照。两模式互斥。中点point及声明sources、coordinate_id／xy快照沿用已有机制；坐标解析结束后才关联中点值。

弦／匿名对保留交点声明、中点别名、原坐标事实的来源并集，中点值来源仍为别名与坐标。绑定时重新核验pair_id、端点名字、Point声明和弦身份，再复用原坐标快照检查；缺坐标不可应用、符号未定、过期坐标冲突。端点记录丢失或错绑也不可应用，不回退到匿名中点直接执行。

同弦同中点反序重复合并来源；同弦不同中点名、缺少唯一弦、重复端点、中点与端点同名拒绝。明确不同点对的两条弦可以共享一个M，但保持各自身份。原PointOnCurve(M,l)由既有解析保留，所得线必须通过中点；它不能代替中点声明。已有端点坐标仍经原公共核验，不能绕过曲线／直线归属。

## 本批文件与核心定义

- `src/state/midpoint_alias_facts.py` → 扩展现有别名模块。ChordMidpointAlias将segment改为可空，新增pair_id、endpoints，保存命名无序对的身份快照。collect_midpoint_aliases新增端点语法并按唯一ChordEndpointNames关联；check_midpoint_alias按两种来源分别核验身份，再复用坐标快照检查。resolve_midpoint_aliases原样复用；模型计算、提案、应用器提交与查询未修改。
- `tests/test_bound_endpoint_midpoint_alias.py`（新增）→ 37项测试。验证两原题两链、来源／初态、反序／重排／重复、歧义／矛盾、缺／符号坐标、三个模型中的身份与坐标篡改回滚、已有端点核验和共享中点隔离。
- `docs/开发规格/artifacts/endpoint_midpoint_alias_traces.json`（新增）→ 保存两个初态及四条固定执行轨迹，包含端点身份、别名、原坐标快照和模型读取来源，供回放复核。
