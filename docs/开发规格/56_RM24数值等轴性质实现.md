# RM24数值等轴性质实现

日期：2026-11-23。承接[规格55](55_RM24数值等轴性质契约.md)。

## 文件与核心职责

- `src/solver/equal_axis_operations.py` → 新增数值资格计算。equal_axis_eccentricity核验有限正半轴平方且a²=b²，返回√2，供模型提案使用，不修改状态。
- `src/theorems/equal_axis_proposals.py` → 新增RM24绑定与提案。check_equal_axis_binding核对唯一双曲线方程；derive_equal_axis_eccentricity复用参数／框架核验，检查来源及已有c²一致性，提出eccentricity属性和等轴核验证据，交应用器提交。
- `src/theorems/models/model_024.py` → 扩展模型入口。propose_bound调用严格数值提案，保留旧入口隔离，不复用旧can_apply的放宽资格。
- `src/theorems/bound_application.py` → 扩展动作编排。enumerate_actions产生绑定曲线／方程的RM24候选，check_binding分派资格检查；属性提交、幂等和冲突回滚复用既有应用器。
- `tests/test_bound_equal_axis.py` → 新增19项测试。核验两题、换轴、缩放、非等轴、多曲线隔离、来源、过期原式、c²／e矛盾、重复及回滚，并对照既有离心率链。

## 有限接口与结果

模式derive_equal_axis_eccentricity绑定curve和equation_id，要求唯一Hyperbola方程、已提交RM5/6的参数／原点x或y轴框架及来源。公共操作要求有限正数值a²=b²；数值不等轴返回inapplicable，未定符号返回undetermined。原式与已提交参数不一致、已有c²≠a²+b²或已有e矛盾，拒绝提交。多条曲线方程保守拒绝，包括重复方程；不任选其一。

输出复用properties[(curve,'eccentricity')]及EccentricityQuery只读查询。operations记录轴向、a²、b²及等轴成立证据；不新增equal_axis状态字段，不生成c²／焦点／渐近线，不强制RM12／13。已有正确e返回no_op且不改状态。

650／1412原始输入固定RM5→RM24均得√2；y轴诊断用RM6→RM24。两题与既有RM5→RM12→RM13结果一致，增加独立模型路径，不表示新增可解题数量或自主选择能力。[实际轨迹](artifacts/equal_axis_traces.json)保存输入、数据哈希、状态变化与来源；旧equal_axis_contract.json仍是设计审查。
