# RM5→RM21 首条执行链

日期：2026-09-23。范围：绑定执行契约的小闭环，不是完整 EGR／神经选择器集成。

## 已实现行为

输入仅使用 ID 2 的 `fact_expressions` 和 `query_expressions`，固定执行 RM5→RM21，得到 **m=5**。不使用 `models`、`process` 或参考答案作决策。

- `TransitionState` 保存曲线归属、方程 ID、原始表达、分母定义域、查询、对象属性、标量赋值及推导来源；初始化不执行定理。
- 同一套状态构造和 `BoundApplicator` 可用于指定动作回放。RM5/RM21 在原模型类上增加 `propose_bound`；旧 `can_apply/apply` 保持不变。
- RM5 将 G.a_sq=4、G.b_sq=m² 写入状态；RM21 绑定 G 的已知渐近线，形成 25/4−m²/4=0，求实根并用条件筛选。
- 应用器在隔离副本上获得候选变化，检查后一次性提交；失败不改变调用方状态，重复动作返回 `no_op`。
- 新赋值 m=5 触发有记录的受限归约，将已有 G.b_sq=m² 更新为 25；原表达保留在前一步 delta 和来源中。
- 抽取器只读取已确定的查询值；28 维 AbstractState 提供兼容视图，尚未训练新的对象感知编码器。

实际输出：[id2_bound_trace.json](artifacts/id2_bound_trace.json)。含绑定、状态版本、delta、输入事实 ID、实根集合、逐根条件检查与归约记录；是可审阅的诊断格式，不是最终训练数据 schema。

## 有意保留的边界

- 这是原点中心、轴对齐双曲线 RM5 与 RM21 反向约束模式。RM21 正向生成渐近线的新接口尚未实现；旧实现仍保留。
- 解析支持本切片所需的声明、算术、单个等式、比较约束和 `Expression(OneOf(Asymptote(G)))`；其他输入显式拒绝。
- 参数求解限至多二次的一元实多项式。未确定的条件返回 `undetermined`；没有强制进程级计算超时，不承诺任意复杂输入的时限。
- 无 m>0 时保留 {-5,5} 并返回 `undetermined`，不擅自选择；还未实现多分支后续搜索。
- 小闭环入口要求一个曲线—已知渐近线绑定；应用器本身支持不同曲线的独立绑定。多个入口候选返回未确定，不暗中挑第一个。
- 未替换旧 `ReasoningEngine`、`StateSequenceBuilder` 或训练入口；它们原有的全局参数、失败后续等问题尚未因此修复。
- `TransitionState` 是新契约的迁移状态，不与旧 `SymbolicState` 自动双向同步。后续扩大模型范围时再决定统一迁移接口。
