# EGR 开发规格

日期：2026-09-23。版本：0.3，增加 RM5→RM21 首条运行时验证。

## 本批范围

本目录为“状态—模型—操作”的开发依据，不是已实现功能报告。以圆锥曲线状态转换求解为主线，覆盖双层状态、80 个高层推理模型、公共符号操作、模型应用与可信训练轨迹。当前不开展 Entropy、LLM 实验或选择器训练；已完成 RM5→RM21 的首批代码实现。

本批落实 D1–D4，累计整理五个真实案例，建立 80 个模型的简要职责与计算依赖表。已全量统计原始模型标注题数，但没有进行全量题目语义审计或完成 80 个模型的详细执行规格。

## 阅读顺序

1. [真实题目转换案例](05_真实题目转换案例.md)：先看具体需求与数学推导。
2. [状态表示与应用器接口](02_状态表示与应用器接口.md)：再看已确认的 D1–D4 和从新案例归纳的结构补充。
3. [80 个模型职责与依赖索引](04_模型规格索引.md)：全库导航、操作依赖、标注题数及候选案例。
4. [RM5→RM21 实现记录](07_RM5_RM21实现记录.md)：实际运行结果、代码文件、命令和当前边界。

## 状态标签

- **原始记录**：来源字段及模型列表，原样保留。
- **数学核验**：本批独立整理推导并进行 SymPy 精确代数检查；不等于独立人工复核或求解器回放。
- **接口草案**：建议的状态结构、应用方式和操作职责，尚未实现。
- **待定映射**：数学推导明确，但归属哪个高层模型／应用方式尚未固定。
- **运行时验证**：实际执行器完成状态转换及检查后使用；ID 2 已完成绑定执行切片验证，其他四例仍为数学／规格案例。

数学检查覆盖五题的关键约束、ID 5 的方向／条件不足构造探针、ID 51 的两个不同合法实例，以及 RM34/39 的公式约定。使用 SymPy 精确代数检查，不使用现有 EGR 推理引擎；不是独立人工复核。
