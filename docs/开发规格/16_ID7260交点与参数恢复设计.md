# ID 7260：交点事实与两类参数恢复

日期：2026-10-02。状态：D5 已获用户确认，交点事实与参数子链已实现；原始距离查询尚未接通。

## 原始输入与结论

```text
H: Line;Expression(H) = (a*x + y - 4 = 0);a: Number;
G: Parabola;Expression(G) = (y^2 = 2*(p*x));p: Number;p>0;
Coordinate(OneOf(Intersection(H, G))) = (1, 2)
```

查询：`Distance(Focus(G), H)`。

已知交点 P=(1,2) 同时属于 H、G。代入直线得 a+2−4=0，a=2；代入抛物线得 4−2p=0，p=2；焦点为 (1,0)。到 2x+y−4=0 的距离为 2/√5=2√5/5。

独立 SymPy 核验了上述等式、距离及两种参数恢复顺序。两次求参在本题中相互独立，均在距离步骤之前；不据此把数据集弱标注或某条线性顺序视为唯一正确轨迹。该核验不是执行器回放。

D5 的依据：RM72 当前为点斜式，扩展其反向一致性模式比把任意代入归为 RM78 更贴合关系本身。本题 k=−a、b=4，代入 P 得 2=−a+4。**本批已新增 recover_from_point 绑定模式；正向点斜式的旧接口保留，尚未迁移为新绑定模式。**

RM78 已确认职责是参数化及相应代入消元；本题已知交点坐标，不需要消元未知交点，不能仅因弱标注含 RM78 就调用它。若不采用 RM72 扩展，另一方案是单独定义可追踪的通用代数动作；这会涉及选择器标签及 80 个模型体系，改动更大，本批不推荐直接实施。
